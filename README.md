# TRIPORY — 여행 커뮤니티 서비스

여행 후기를 공유하고, 광고성 후기를 자동으로 판별하며, 여행 일정을 공유할 수 있는 여행 커뮤니티 서비스입니다. "트리플" 앱을 벤치마킹하여 개인 프로젝트로 기획·개발했습니다.

> 개발 기간: 2025.10.10 ~ 2025.10.21 · 개인 프로젝트

## 기술 스택

| 구분 | 내용 |
|---|---|
| 프론트엔드 | React, Bootstrap |
| 백엔드 | Node.js, Express |
| 데이터베이스 | MySQL |

## 폴더 구조

```
TRIPORY/
├── client/   # 프론트엔드 (React + Bootstrap)
├── server/   # 백엔드 (Node.js + Express)
└── docs/     # 요구사항명세서 검토 결과, 시연 영상 등 산출물
```

## 실행 방법

### server

```bash
cd server
npm install
npm start
```

### client

```bash
cd client
npm install
npm run dev
```
